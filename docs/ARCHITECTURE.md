# 구조·기술 결정 현황

## 현재 상태

애플리케이션 코드와 런타임 설정은 아직 없다. 직접 개발하여 소스코드를 공개하며, 기존 오픈소스 제품을 포크하는 작업은 현재 계획에 포함하지 않는다.

## 확정한 경계

- 사용 환경은 PC·태블릿·모바일 웹이다.
- 초기 사용자 맥락은 셰프 1명의 식당 운영이다. 다중 사용자·다중 매장 설계는 미정이다.
- 공개 소스코드·개발 문서와 실제 운영 데이터는 분리한다.
- 프로젝트 소스코드와 직접 작성한 문서에는 [MIT 라이선스](decisions/ADR-001-mit-license.md)를 적용한다.
- 예제와 테스트에는 가상 데이터를 사용한다.

| 단계 | 결정할 내용 | 상태 |
| --- | --- | --- |

| 데이터 | 식별 구조·단위·원가·재고 차감·이력 정책 | 미정 |

| 구현 | 프론트엔드·백엔드·라이브러리·패키지·검증 도구 | 미정 |

## 검토 후보

파일 업로드·다운로드, 로컬 파일 접근, DB 기반 저장을 비교한다. 호스팅은 경량 호스팅을 우선 검토하고, 정적 호스팅 또는 NAS·컨테이너 구성의 적합성을 함께 확인한다. 특정 후보를 채택한 상태는 아니다.

실제 운영 조건이 확정되면 [결정 기록](decisions/README.md)에 이유와 대안을 남기고, 이 문서·README·검증 명령을 갱신한다. 확인되지 않은 빌드 명령, 배포 경로, 포트와 인증 구성을 미리 만들지 않는다.
