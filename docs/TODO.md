## 검증과 관리

현재는 문서·링크·제외 규칙·로컬 스킬 설치를 검증한다. 앱 코드와 실행 환경이 생기면 빌드·테스트·수동 확인 방법을 해당 티켓과 README에 추가한다.

세부 목표·완료 조건은 [작업 티켓](tickets/README.md), 변경 결정은 [결정 기록](decisions/README.md)에 남긴다. 중대한 요구사항은 연결된 기획 노트와 함께 갱신하고 완료 또는 미반영 사유를 보고한다. 완료·대체 문서는 필요할 때 [이력 색인](deps/INDEX.md)과 함께 보관한다.
