## 검증 상태

현재는 문서와 Git 제외 규칙을 검증한다. 앱 코드와 실행 환경이 생기면 빌드·테스트·수동 확인 방법을 해당 티켓과 README에 추가한다.

## 관리 규칙

세부 목표·완료 조건·검증 결과는 [작업 티켓](tickets/README.md)에 기록한다. 현재 결정은 [결정 기록](decisions/README.md)에 남긴다. 완료되거나 대체된 문서는 필요할 때 [이력 색인](deps/INDEX.md)과 함께 보관한다.
