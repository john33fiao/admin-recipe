# 할 일

## 현재 단계

2026-10-24에 기존 요구사항과 후속 사용자 결정을 T-001~T-030으로 연결했다. [티켓 색인](tickets/README.md)이 상세 상태와 의존 관계의 정본이며 [요구사항](REQUIREMENTS.md)·[ADR-007](decisions/ADR-007-consumption-and-ticket-scope.md)을 기준으로 구현한다.

2026-10-25 사용자 요청으로 일괄 입력 방식 세 가지를 T-031~T-033 백로그에 추가했다([ADR-008](decisions/ADR-008-bulk-entry-backlog.md)). 같은 날 명시적 재개 요청으로 T-019·T-021의 초기 통합/지정 시연 뒤 T-031~T-033을 실행한다. 세 입력 방식은 CSV/공통 편집표로 통합한다([ADR-010](decisions/ADR-010-unified-bulk-entry.md)). T-001/T-021의 외부 실환경 미검증은 독립적인 일괄 입력 작업을 막지 않는다.

T-001의 로컬 실행·재료 이름/단위 저장·조회는 구현했다. 별도 깨끗한 Windows/Mac·실제 절전 등 필수 검증은 미완료다. OS 간 데이터 왕복은 백로그이며 같은 OS 이동 등 다른 기준은 유지한다. T-002 계산·데이터 계약, T-020 공통 UI와 T-003 재료/사전 가격의 구현·검증을 완료했다. T-005 공통 저장·DB 초안/확정·가격 정정과 T-009의 실제 판매 조건도 검증했다. T-006 발주 작성·수정·취소와 순수 입고 종료 계약을 검증했다. T-007 실제 직접/주문 입고·보유 평균·실제 주문 종료도 검증했다. T-004 레시피·버전·독립 복제와 정확 원가도 검증했다. T-008 실제 여러 투입/결과·원가 배분·보유 이월과 이전 기록 보존도 검증했다. T-010 선택 실사·명시 폐기·판매 개수별 소모/원가 배분과 실제 관측 뒤 생산을 검증했고 T-009의 실제 배분 표시도 완료했다. T-011 지연 입고의 명시 포함 선택·현재 가치/별도 보정·중복 예약 방지와 원문 보존을 검증했다. T-012의 원기록 보존 정정·취소, 판매 재배분·실사/포함 연결 개정과 영향 미리보기도 검증했다. T-013 현재 평균 단가 반품·원입고 한도·정정/복원과 다음 실사 중복 제외도 검증해 T-010의 마지막 기준을 완료했다. T-014 모아 입력의 개별 저장·부분 실패·재시작 복구·실사 순서도 검증했다. T-015 사진·대표·구입처와 과거 자산·원요청 재생·같은 OS 이동도 검증했다. T-016 판매 통계·실사 소모·원가 이력과 현재 직접/간접 연결·역참조도 검증했다. T-017 마지막 실측·이후 변동·상태별 전체 목록과 키보드 접근도 검증했다. T-018 전체 활성 상태·원문/사진·원요청 보존과 재시작 복원도 검증했다. T-019 호환·현재 Mac의 같은 OS 전체 이동과 보존 요청·재복원을 검증했다. 지정 실제 시연과 최종 가상 통합을 실행했고 T-031~T-033의 공통 일괄 입력·관련 수용 검증도 완료했다. T-021의 전체 회귀·release 성능 측정은 진행 중이며 외부 필수 조건은 별도로 남는다.

## 확정한 운영 기준

- 판매 입력만으로 재고를 차감하지 않고 실사에서 소모를 확정한다. 별도의 예상 현재고를 관리하지 않는다.
- 명시 폐기·생산 투입·반품을 제외한 소모를 해당 실사 구간의 메뉴 판매 개수 비율로 배분한다. 판매가 없으면 미배분으로 남긴다.
- 레시피 수량 0·0원 재료를 허용한다. 입고 전 가격 등록과 보유량 0일 때 마지막 유효 단가를 지원한다.
- 레시피 수정은 이후 판매부터 적용하고 과거 버전을 보존한다. 삭제 대신 아카이빙한다.
- 여러 생산 결과물은 주 결과물 원가 100%·나머지 0%를 기본으로 수정 가능하다.
- 반품은 현재 평균 단가로 보유 가치를 차감하고 원구입 금액은 참고로 보존한다.
- 판매가·단순 원가율·판매금액 합계, 여러 사진/대표 사진과 여러 구입처를 포함한다.
- 발주는 내역 저장이며 직접 입고를 허용한다. 1회 실입고로 주문을 종료하고 차이를 남긴다.
- 지연 입고의 이미 실사에 포함된 수량을 확인해 중복을 막는다. 저장·전체 복원·호환·단일 PC 정책은 유지한다.
