# ADR-001: MIT 라이선스 채택

- 상태: 채택
- 결정일: 2026-10-24
- SPDX 식별자: `MIT`
- 적용 원문: [LICENSE](../../LICENSE)

## 배경과 선택

식당 운영 웹 어드민을 직접 개발하고 소스코드를 공개한다. 사용자는 MIT를 우선 선호하며, 프로젝트에 적절한 라이선스를 적용하도록 요청했다.

MIT를 채택한다. 상업적 이용·수정·재배포를 허용하고 저작권·허가 고지를 유지하는 간결한 조건이 현재 공개 방향에 맞는다. 수정본의 비공개 사용·배포·판매는 허용하되 라이선스 고지에 원본 저장소 주소를 남긴다. 이를 위해 URL을 저작권 고지에 포함하고 MIT의 기존 고지 보존 조건을 적용한다.

## 적용 범위

- 이 프로젝트의 소스코드와 직접 작성한 문서에 적용한다.
- 별도 저작권·라이선스가 표시된 제3자 코드·문서·이미지·폰트 등은 해당 조건을 따른다.
- 실제 레시피 배합·매입 단가·매출·거래처·계정 등 운영 자료는 공개 저장소에 포함하지 않는다.
- 루트 LICENSE의 표준 조건은 수정하지 않고, 저작권 고지는 `Copyright (c) 2026 john33fiao (https://github.com/john33fiao/admin-recipe)`로 둔다.

## 영향

- 다른 사람이 상업적으로 사용하거나 수정본을 비공개로 배포·판매할 수 있다.
- 소프트웨어의 복제본 또는 상당 부분에는 원본 저장소 주소가 포함된 저작권 고지와 허가 고지를 유지해야 한다.
- 표준 MIT 원문의 보증 부인과 책임 제한을 유지한다.
- 이후 도입하는 의존성·외부 자료의 라이선스와 고지 의무는 별도로 확인한다.

## 재검토 조건

수정본 공개 의무나 명시적 특허 조건 등 새로운 요구가 생기면 별도 결정 기록으로 검토한다.
