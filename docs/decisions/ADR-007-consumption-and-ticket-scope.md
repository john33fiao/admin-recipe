# ADR-007: 실사로 소모 확정·판매 개수 배분과 원가 정책

- 상태: 채택 — 운영 정책 확정, 구현 전
- 결정일: 2026-10-24
- 관련: C-01~C-03, D-01~D-05, D-08~D-13
- 근거: 요구사항 티켓 전환 중 사용자의 항목별 답변과 후속 사례 확인
- 대체: ADR-003·ADR-004의 판매 즉시 차감, 실사 부족 자동 폐기, 메뉴별 소모 배분 제외, 재고 부족 확정 금지, 반품의 원구입금액 가치 차감. 실행·저장·배포와 나머지 운영 결정은 유지한다.

## 결정

| ID | 확정 사항 |
| --- | --- |
| P-01 | 1차에 판매가·단순 원가율(식재료비÷입력 판매가)·판매금액 합계를 포함한다. 세금 자동 분리·할인·결제 관리 제외 |
| P-02 | 레시피 수량 기본값 0. 수량 없이도 판매 등록 가능. 이후 수량 변경은 앞으로 등록하는 판매에만 적용 |
| P-03 | 보유량 0일 때 마지막 유효 단가로 원가 계산. 입고 전 재료·계산용 가격 등록 지원. 가격 입력만으로 보유 수량/가치를 만들지 않음 |
| P-04 | 0원 재료·결과물 허용. 여러 결과물은 주 결과물 100%·나머지 0% 기본, 수정 가능하며 투입 원가 합계 보존 |
| P-05 | 발주는 주문 내역 저장. 거래처명·예정일·예상 금액 선택, 직접 입고 허용. 발주서 출력·외부 전송 제외 |
| P-06 | 1회 실입고로 주문 종료. 주문량·실입고량·차이 보존, 잔여 입고 추적은 백로그 |
| P-07 | 지연 입고의 관련 실사·이미 포함된 수량을 사용자가 확인. 수량 중복 없이 금액 보정안을 확인하고 현재 시점 확정 |
| P-08 | 예상 재고를 별도로 관리하지 않음. 판매만으로 차감하지 않고 실사로 소모 확정. 명시 폐기 등을 제외한 소모를 판매 개수 비율로 배분 |
| P-09 | 판매 기록은 소모 연결과 판매 수량/금액 집계에 사용. 고객 환불 제외. 오입력 정정으로 실물 반환을 추정하지 않음 |
| P-10 | 반품은 현재 평균 단가로 보유 가치 차감. 구입 당시 금액은 참고 금액으로 보존 |
| P-11 | 수정 전 버전·당시 레시피/가격 보존, 삭제 대신 아카이빙. 다른 차원 단위 변경은 새 품목 |
| P-12 | 여러 사진·대표 1장·여러 구입처 링크/설명 지원 |

## 후속 질문의 확정 결과

| ID | 사용자 선택과 수용 사례 |
| --- | --- |
| Q-01 | 판매 개수 비율을 기본으로 채택. 직전 해당 품목 실사 이후의 직접 참조 메뉴 판매를 대상으로 한다. A 3개·B 1개에 소모 400g이면 300g·100g. 대상이 없으면 미배분 소모. 판매 직접 선택은 T-030 백로그 |
| Q-02 | 실사 중심 방식 A 채택. 판매는 수량·금액 기록만 하고 재고를 차감하지 않는다. 마지막 확인 수량·확인 시각을 표시한다. 이전 10kg·명시 폐기 1kg·이번 실사 6kg이면 소모 3kg |
| Q-03 | 레시피 변경은 앞으로 등록하는 판매부터 적용. 앞선 ‘사후 적용’ 표현을 구체화하며 과거 판매 자동/일괄 재계산은 채택하지 않음 |
| Q-04 | 주 결과물 100%·나머지 0% 기본, 사용자 수정 가능. 10,000원 투입이면 결과물 원가 배분 합계도 10,000원 |
| Q-05 | 현재 평균 단가 차감 채택. 현재 2kg·20,000원 중 1kg 반품 뒤 1kg·10,000원. 원구입 30,000원을 직접 차감하여 음수 가치를 만드는 안은 채택하지 않음 |

## 계산·이력의 경계

실사 소모는 직전 품목 실사에 이후 확정 입고·생산 유입을 더하고 생산 투입·반품·명시 폐기를 뺀 정산 기준과 이번 실측 수량의 차이다. 이 기준은 소모 정산용이며 별도의 예상 현재고 기능으로 운영하지 않는다. 빈 실사 칸은 미확인이고 명시한 0은 확인한 수량이다.

판매에 배분하는 소모와 명시 폐기를 구분한다. 소모 원가는 보유 가치에서 차감한다. 잔량이 있는 명시 폐기는 손실을 잔존 재고에 배분하고 전량 명시 폐기는 손실로 종료하는 기존 결정을 유지한다. 생산 투입·반품·폐기·이전 배분을 다시 판매 소모로 계산하지 않는다. 원기록과 정정·배분 근거를 보존한다.

단위·반올림·원가 정밀도, 첫 실사, 품목별 실사 기간과 입력 중 상태 변경, 실사 후 지연 입고/정정의 금액 보정은 [T-002](../tickets/T-002-domain-contract.md)의 구현 설계다. 이미 확정한 정책을 재질문하지 않고 수량/가치 보존과 중복 방지 사례로 검증한다. 정책으로 결과를 설명할 수 없는 새 사례만 따로 확인한다.

## 영향

판매 당시 레시피 기준 원가와 실사에서 배분한 소모 원가는 의미가 다르다. 통계와 운영 화면에서 구분하며 배분 결과를 메뉴별 직접 측정치로 표현하지 않는다. 판매 때 재고 부족으로 확정을 막거나 실사 부족을 자동 폐기로 만드는 기존 계획은 구현하지 않는다.
