# T-030: 소모를 연결할 판매 직접 선택

- 상태: 백로그 — 구체화/착수 대기
- 단계: 백로그
- 작성일: 2026-10-24
- 관련 요구: D-02~D-04, P-08
- 선행: [T-010](T-010-stocktake-and-waste.md), [T-012](T-012-corrections-and-versions.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

기본 판매 개수 비례 배분으로 설명하기 어려운 소모를 사용자가 연결한다.

## 포함 범위

실사 소모의 연결 대상 판매를 직접 선택하는 후속 기능을 보존한다. 기본 배분은 판매 개수 비율로 유지한다.

## 제외 범위

현재 1차 직접 선택 기능.

## 수용 기준

- [ ] T-030-01: 현재 기본 자동 배분과 사용자가 직접 지정한 연결을 구분한다.
- [ ] T-030-02: 선택 가능한 판매 범위·부분 연결·배분량 수정·미배분 처리와 총량 보존 기준을 착수 시 확정한다.
- [ ] T-030-03: 이미 확정된 배분 변경은 원기록/정정 이력으로 보존하며 재고를 다시 차감하지 않는다.
- [ ] T-030-04: 아카이브·정정된 판매·비축 하위 재료에 잘못 연결하지 않도록 수용 사례를 만든다.

## 검증 방법

기본 배분→선택 연결→재선택·미배분·정정 후 총소모/가치 불변 사례 검토 후 구현 테스트.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

백로그 착수 승인 및 선택/부분 배분 UI·정정 범위

## 검증 결과

미실행 — 요구사항을 티켓으로 전환한 상태다. 수용 기준 체크는 실제 구현·검증 근거가 생긴 뒤 갱신한다.
