# T-016: 판매 통계·실사 소모·원가 이력 조회

- 상태: 완료 — 일곱 수용 기준·RTD Before4/After13·관련 실제 검증 완료

- 관련 요구: D-02~D-04·D-09, P-01·P-08·P-11
- 선행: [T-014](T-014-closing-workspace.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

판매와 재료 소모의 변화를 기간별로 확인하고 숫자의 근거를 추적한다.

## 포함 범위

판매 개수/금액 표·시계열, 재료별 실사 소모와 메뉴 배분·미배분, 입고·생산·폐기·반품·실사 이력과 양방향 연결을 제공한다.

## 제외 범위

POS·세무/회계 보고서·메뉴별 실제 계량을 했다는 표현.

## 수용 기준

- [x] T-016-01: 자동 입력 시각 기준 기간 조회를 지원하고 기간 경계·시간대·정정 반영 기준을 표시한다.
- [x] T-016-02: 판매 수량/금액 합계가 당시 버전의 유효 기록과 일치한다. 가격 변경·아카이브로 과거 기록이 사라지지 않는다.
- [x] T-016-03: 재료별 실사로 확정한 소모 총량=판매별 배분량+미배분량이다. 판매 개수 비율로 배분했음을 표시하고 직접 측정한 메뉴별 사용량이라고 단정하지 않는다.
- [x] T-016-04: 실사 전 소모 미확정·판매 없음·명시 0·기록 없음과 기간 바깥 기록을 구분한다.
- [x] T-016-05: 명시 폐기·생산 투입·반품은 판매 소모와 구분하고 금액을 이중 합산하지 않는다.
- [x] T-016-06: 메뉴에서 직접 구성 재료와 비축품을, 재료에서 직접 사용 메뉴를 조회한다. 간접 연결은 경로를 표시하고 비용/소모에 중복 합산하지 않는다.
- [x] T-016-07: 레시피 기준 원가와 실사 소모에 배분된 원가를 구분하여 표시한다.

## 검증 방법

혼합 이벤트 가상 기간 데이터의 합계 대조, 날짜 경계·미측정·정정·아카이브·비축 중첩·표/그래프 일치 UI 테스트.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

운영 정책 질문은 확정됐다. 화면 구성·스키마·오류 표시·정밀도 등은 T-002와 기존 구조에 맞춰 설계한다. 새 운영 판단이 필요하면 예시와 영향을 제시하고 해당 부분만 보류한다.

## 검증 결과

[설계·Before4](T-016-plan.md)의 일곱 기준을 [실제 검증·After13](T-016-verification.md)에 대응했다. Rust 첫 전체560통과/2실패 뒤 수정한 HTTP6건과 내부 할당 수정 후 영향23건을 통과해 서로 다른562개 시험의 근거를 확보했다. UI124·기존 브라우저28건과 신규 첫6건/후속1건·키보드·6화면 및 타입/정적 검사도 통과했다. 스키마와 운영 정책은 유지한다. 다음은 T-017 운영 개요이며 T-001의 필수 외부 환경과 T-021 실제 자료 시연·배포 준비는 미완료다.
