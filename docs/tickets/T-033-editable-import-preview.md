# T-033: CSV 업로드 확인 화면에서 편집 후 일괄 등록

- 상태: 완료 — CSV/공통 편집표 구현·관련 수용 검증 완료
- 단계: 이번 재개의 추가 실행 범위
- 작성일: 2026-10-25
- 관련 요구: D-01·D-05·D-08·D-09, C-05
- 선행: [T-031](T-031-file-bulk-import.md)·[T-032](T-032-sheet-bulk-entry.md)의 요구 정리. 개별 구현 완료를 필수 순서로 정하지 않는다.
- 기준: [요구사항](../REQUIREMENTS.md), [백로그 등록 결정](../decisions/ADR-008-bulk-entry-backlog.md)

## 목적

파일 업로드와 시트 직접 입력을 결합하여, 업로드한 값을 파일로 돌아가지 않고 확인 화면에서 고친 뒤 등록한다.

## 포함 범위

CSV 파일 업로드 → 시트형 확인 화면 → 데이터 직접 수정 → 수정 결과와 DB에 추가할 내용 확인 → 등록 버튼으로 일괄 등록하는 통합안이다. 재료·메뉴와 입고 수량·단위·구입금액·입고일에 적용한다.

## 제외 범위

특정 과거 자료 정제·초기 이관, 앱 검증을 거치지 않는 직접 DB 주입. 이미 등록한 기록의 수정은 기존 업무 정정·버전 정책을 따른다.

## 수용 기준

- [x] T-033-01: CSV 업로드 결과를 시트형 확인 화면으로 보여주고 등록 전에 셀 값을 직접 수정할 수 있다.
- [x] T-033-02: 값을 수정하면 오류·참조·등록 예정 내용을 다시 검증·표시하고, 등록 버튼은 최종 확인한 수정본을 반영한다.
- [x] T-033-03: 재료·메뉴·입고를 지원하고 기존 단위·빈 값/0원·입고일·지연 입고 중복 방지·버전·JSON 기록·재시도 정책을 유지한다.
- [x] T-033-04: 등록 전 편집·취소와 실제 확정을 구분하고 등록 결과를 조회한다. 오류 행의 전체/일부 처리와 중복 등록 방지는 착수 때 정한 정책으로 검증한다.
- [x] T-033-05: T-031·T-032와 공통화하거나 통합할 범위를 정하되, 세 백로그를 모두 별도 기능으로 구현할 것을 전제하지 않는다.

## 검증 방법

가상 CSV 업로드→오류·값 수정→재검증→미리보기→등록→조회로 최종 수정본이 저장되는지 확인한다. 입고 수량·금액 수정, 편집 취소, 재시도와 지연 입고를 포함하고 [공통 완료 조건](README.md#공통-완료-조건)의 해당 검증을 수행한다.

## 채택한 기술 선택

T-031/T-032와 같은 편집표·검증·실행기로 통합하고 우선순위를 이번 재개 범위에 반영했다. 형식·셀/행 편집·중복/부분 성공·임시 입력 보존은 ADR-010을 따른다. 등록한 원기록은 성공 행을 다시 편집하여 바꾸지 않고 기존 정정·복원 절차를 사용한다.

## 검증 결과

[공통 검증 기록](../refs/T-031-T-033-verification.md)에 수용 기준별 실제 결과·변경 파일·최초 실패/수정·최종 실행과 세 티켓 각각의 After13을 기록했다. UI164·최종 입고 HTTP12(신규4 포함)·bulk 브라우저11·6화면/키보드/3종 양식을 확인했다. [공통 Before4/계획](T-031-T-033-plan.md)과 [ADR-010](../decisions/ADR-010-unified-bulk-entry.md)의 채택 기술 계약을 따른다. T-021의 전체 회귀/성능·필수 외부 조건은 이 티켓의 완료와 구분한다.
