# T-026: 보관 위치별 재고·이동 요구 구체화

- 상태: 백로그 — 구체화/착수 대기
- 단계: 백로그
- 작성일: 2026-10-24
- 관련 요구: D-08
- 선행: 없음
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

필요해질 때 같은 품목의 보관 장소와 이동을 구분한다.

## 포함 범위

위치 관리·위치별 실사/이동의 범위와 기존 전체 품목 재고와의 관계를 설계한다.

## 제외 범위

현재 1차 위치 강제·다중 매장.

## 수용 기준

- [ ] T-026-01: 위치 추가/변경/아카이브와 과거 위치명을 보존할 수 있는 요구를 정의한다.
- [ ] T-026-02: 위치 이동을 입고·판매 소모로 중복 처리하지 않고 품목 전체 수량·가치 합계를 보존한다.
- [ ] T-026-03: 위치별 실사 기간·판매 귀속·평균 원가를 품목 전체로 둘지 위치별로 둘지 착수 전에 확정한다.
- [ ] T-026-04: 기존 위치 없는 자료의 표시/마이그레이션 기준과 수용 사례를 만든다.

## 검증 방법

한 품목 두 위치 이동·위치별 실사·합계 보존 사례로 요구 검토 후 검증 설계.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

백로그 착수 승인 및 위치별 실사/가치 정책

## 검증 결과

미실행 — 요구사항을 티켓으로 전환한 상태다. 수용 기준 체크는 실제 구현·검증 근거가 생긴 뒤 갱신한다.
