# T-022: 2차 내일 메뉴·공유 재료 계획 요구 구체화

- 상태: 2차 — 구체화/착수 대기
- 단계: 2차
- 작성일: 2026-10-24
- 관련 요구: D-01·D-04·D-06
- 선행: [T-021](T-021-first-release-verification.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

확인된 재료와 입고 예정량으로 내일 제공할 메뉴·수량을 검토한다.

## 포함 범위

보유 재료·미입고·추가 발주를 분리한 계획 기능의 요구를 구체화한 뒤 구현한다. 자동 예상 재고 운영과 혼동하지 않도록 계획용 계산임을 명시한다.

## 제외 범위

현 단계 자동 구현·기준 수율·설비/작업 자동 일정.

## 수용 기준

- [ ] T-022-01: 메뉴별 계획 수량·공유 재료 총소요량과 부족 재료를 비교하는 수용 사례를 정한다.
- [ ] T-022-02: 실사 수량의 확인 시각·후속 확정 변동·미입고 예정량·가상 추가 발주를 구분하며 계획이 실제 재고를 바꾸지 않는다.
- [ ] T-022-03: 한 재료를 여러 메뉴가 공유해도 각 메뉴의 단독 최대량을 동시에 제공할 수 있다고 표시하지 않는다.
- [ ] T-022-04: 원물과 손질분을 구분하고 기준 수율 자동 역산을 재도입하지 않는다. 실제 생산량 추정이 필요한 부분은 별도 결정한다.
- [ ] T-022-05: 예약/배정 여부·계획 저장/변경·당일 생산 연결·예정 입고 포함 기준을 사용자와 확정하고 설계/구현 하위 작업과 검증을 작성한다.

## 검증 방법

먼저 가상 공유 재료 사례로 요구 검토. 구현 착수 기준 확정 뒤 계산·계획/실제 분리 테스트를 정한다.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

2차 착수 시 계획의 배정·예약·생산량 추정·예정 입고 신뢰 기준 확정

## 검증 결과

미실행 — 요구사항을 티켓으로 전환한 상태다. 수용 기준 체크는 실제 구현·검증 근거가 생긴 뒤 갱신한다.
