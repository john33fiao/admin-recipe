# T-013: 구매 취소·반품과 현재 재고 가치

- 상태: 완료 — 평균 단가 반품·원입고 한도·정정과 실사 연결 검증
- 단계: 1차
- 작성일: 2026-10-24
- 관련 요구: D-04·D-08, P-10
- 선행: [T-007](T-007-receipts.md), [T-012](T-012-corrections-and-versions.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

반품한 수량과 현재 평균 단가에 따른 원가를 차감하여 남은 재고 가치를 파악한다.

## 포함 범위

원입고 참조·구입 당시 참고 금액 보존, 반품 수량·현재 평균 원가 차감과 반품 이력 조회를 구현한다.

## 제외 범위

고객 환불·결제 정산·세무 처리.

## 수용 기준

- [x] T-013-01: 원입고·반품 수량·구입 당시 참고 금액을 연결해 보존한다. 이미 반환한 수량을 중복 반환하지 않는다.
- [x] T-013-02: 보유 가치는 반품 시점 현재 평균 단가×반품 수량만큼 차감한다. 구입 당시 금액이나 환급액으로 현재 보유 가치를 차감하지 않는다.
- [x] T-013-03: 현재 2kg·20,000원에서 1kg 반품하면 1kg·10,000원이다. 원구입 30,000원은 참고 금액으로 보존한다.
- [x] T-013-04: 미입고 취소는 주문 상태만 바꾼다. 반품은 확정 재고 변동으로 다음 실사 소모에서 제외한다.
- [x] T-013-05: 전량 반품은 잔존 금액의 정밀도 잔여를 처리해 수량·보유 가치가 함께 0이 되도록 한다. 가격이 없는 경우 확인할 금액/가격을 안내한다.
- [x] T-013-06: 반품 정정은 원반품과 연결하며 동일 요청 재시도로 두 번 차감하지 않는다.

## 검증 방법

혼합 가격 입고 후 평균 단가 반품·전량 반품·원구입 참고 금액 보존·미입고 취소·다음 실사 중복 방지·재시도 단위/통합/UI 테스트.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

운영 정책 질문은 확정됐다. 화면 구성·스키마·오류 표시·정밀도 등은 T-002와 기존 구조에 맞춰 설계한다. 새 운영 판단이 필요하면 예시와 영향을 제시하고 해당 부분만 보류한다.
