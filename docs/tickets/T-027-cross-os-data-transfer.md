# T-027: Windows↔macOS 데이터 왕복 검증

- 상태: 백로그 — 구체화/착수 대기
- 단계: 백로그
- 작성일: 2026-10-24
- 관련 요구: D-12~D-13
- 선행: [T-019](T-019-data-compatibility.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

호환 OS별 빌드 사이에서 자료·사진을 옮기는 지원 목표를 실제 환경에서 확인한다.

## 포함 범위

Windows x64와 macOS ARM64 사이의 정상 종료된 db/·DB·JSON·사진 이동과 왕복 일관성을 검증한다.

## 제외 범위

공동 접속·실시간 동기화·지금 즉시 실행.

## 수용 기준

- [ ] T-027-01: 각 대상 환경·앱 버전·검증 자료 출처를 기록하고 가상 자료만 사용한다.
- [ ] T-027-02: 정상 종료된 db/를 반대 OS의 호환 빌드에서 열고 변경 후 돌아와 데이터·사진·버전/배분 참조를 비교한다.
- [ ] T-027-03: 파일명 대소문자·한글/공백 경로·사진 해시·JSON 형식과 권한 차이를 확인한다.
- [ ] T-027-04: DB만/JSON만 이동한 구조화 자료와 사진 포함 db/ 이동을 구분한다. 지원 범위·실패 복구 절차를 기록한다.
- [ ] T-027-05: 2026-10-24 결정에 따라 T-001 완료 필수 조건에서 제외된 상태를 유지하고 실행 전까지 미검증으로 표시한다.

## 검증 방법

실제 두 OS의 가상 전체 자료 왕복·원본 보존·정상 종료·상태 비교. 한 OS의 테스트로 대체하지 않는다.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

백로그 착수와 두 OS의 검증 환경 확보

## 검증 결과

미실행 — 요구사항을 티켓으로 전환한 상태다. 수용 기준 체크는 실제 구현·검증 근거가 생긴 뒤 갱신한다.
