## 구현·검증 경계

스키마 v14·JSON v2를 유지하는 조회 기능이다. 자동 원입력 시각으로 기간을 고르고 현재 유효 정정을 적용한다. 판매·실사 소모·종류별 업무와 실제 상세 링크, 현재 품목 연결을 제공한다. 계획의 수용 기준과 실제 시험을 대조하며 미실행을 통과로 기록하지 않는다.

## 실행 기록

- 변경 전 실행 파일에서 정상 API로 가상 품목·빈 레시피를 만들고 새 경로를 호출했다. 통계 GET·실제 레시피 연결 GET·통계 화면은404로 실패했고 기존 세션/Origin 보호와 state 보존은 통과했다. 결과5통과/3실패·종료1이다. 레시피가 없는 원물의404를 기능 실패로 계산하지 않았다.
- UI에서 기존 시각 표시 함수가 조회 결과의 지정 시간대를 받지 못하는 경계를 실제 실패로 확인했다. PC 시간대와 보고서 표시 시간대가 다르면 시각 표시가 달랐으며 단위 실행은 종료1이었다. 기존 기본 표시는 유지하면서 명시 시간대 표시를 추가했고 후속 단위 검사에서 통과했다.
- 정적 독립 검토에서 현재 연결의 분자 수량을 해석할 owner 레시피 기준 개수가 필요함을 확인해 step DTO와 계획에 포함했다. 이 발견은 실행 실패로 표현하지 않는다.
