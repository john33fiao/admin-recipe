# T-025: 부분 입고와 미입고 잔량 추적

- 상태: 백로그 — 구체화/착수 대기
- 단계: 백로그
- 작성일: 2026-10-24
- 관련 요구: D-08, P-06
- 선행: [T-006](T-006-purchase-orders.md), [T-007](T-007-receipts.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

한 주문이 여러 번 나누어 도착할 때 남은 주문량을 추적한다.

## 포함 범위

현재 1회 입고 종료 정책의 후속 확장으로 여러 입고·잔량·잔여 취소 흐름을 정의한다.

## 제외 범위

현재 1차의 잔여 재입고 추적.

## 수용 기준

- [ ] T-025-01: 원주문·각 실입고·잔여량을 연결하고 각 입고만 실제 재고에 반영한다.
- [ ] T-025-02: 마지막 입고/잔여 취소·초과 입고·실측 차이의 종료 기준을 착수 시 확정한다.
- [ ] T-025-03: 이미 1회 종료한 주문은 재해석하지 않고 당시 상태·차이를 보존한다.
- [ ] T-025-04: 중복 입고·취소·정정과 데이터 마이그레이션 검증 기준을 마련한다.

## 검증 방법

10kg 주문→4kg→6kg, 잔여 취소·초과/차이 사례를 결정 후 계산/상태 테스트.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

백로그 착수 승인 및 잔여 종료/초과 입고 정책

## 검증 결과

미실행 — 요구사항을 티켓으로 전환한 상태다. 수용 기준 체크는 실제 구현·검증 근거가 생긴 뒤 갱신한다.
