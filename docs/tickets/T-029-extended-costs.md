# T-029: 포장재·소모품·인건비 등 원가 확장 검토

- 상태: 후속 검토 — 구체화/착수 대기
- 단계: 후속 검토
- 작성일: 2026-10-24
- 관련 요구: D-01·D-04·D-06
- 선행: [T-021](T-021-first-release-verification.md), [T-023](T-023-work-time-history.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

식재료 원가 이후 추가 비용을 중복 없이 계산할 확장 여지를 보존한다.

## 포함 범위

포장재·소모품·실제 작업시간 기반 인건비의 도입 범위와 원가율/세금 표시 등 부가 정책을 결정한다.

## 제외 범위

현재 1차 인건비·자동 세금·회계 기능.

## 수용 기준

- [ ] T-029-01: 식재료 원가와 추가 비용 범주·기준 단위를 구분하고 입력/계산/표시할 금액을 정한다.
- [ ] T-029-02: 인건비는 직접 작업·대기·공통 작업과 생산량 기준을 정하고 병행 작업 시간을 중복 배분하지 않는다.
- [ ] T-029-03: 현재 1차 단순 원가율을 세금 자동 분리·목표 경고로 임의 변경하지 않는다. 필요한 경우 별도 승인과 수용 사례를 기록한다.
- [ ] T-029-04: 확장 승인 후 데이터/화면/계산 구현을 나누며 기존 식재료 원가 이력을 재작성하지 않는다.

## 검증 방법

가상 배치/개당 원가와 병행 작업 사례로 정책 검토 후 단위/통합 검증 계획.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

후속 확장 우선순위·원가 범주·배분 정책

## 검증 결과

미실행 — 요구사항을 티켓으로 전환한 상태다. 수용 기준 체크는 실제 구현·검증 근거가 생긴 뒤 갱신한다.
