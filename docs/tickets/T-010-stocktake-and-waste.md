# T-010: 명시 폐기·선택 실사와 판매 소모 배분

- 상태: 대기 — 선행 티켓 완료 후 착수
- 단계: 1차
- 작성일: 2026-10-24
- 관련 요구: C-02, D-02~D-04·D-08, P-08
- 선행: [T-008](T-008-production.md), [T-009](T-009-sales-consumption.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

실측 현재고로 소모를 확정하고 명시 폐기와 판매에 연결한 소모를 구분한다.

## 포함 범위

지정 재료 폐기/직원식, 선택 품목·일괄 실사, 확정 소모의 판매 연결, 초과 조정과 이력 조회를 구현한다.

## 제외 범위

소비기한 추적·자동 폐기 추정·특정 메뉴의 실제 사용량을 측정값처럼 단정.

## 수용 기준

- [ ] T-010-01: 확인한 품목만 실사하고 빈칸은 미확인으로 유지한다. 명시한 0은 실제 현재고 0이다. 일괄 입력도 지원한다.
- [ ] T-010-02: 직전 품목 실사 이후 확정 입고·생산 유입/투입·반품·명시 폐기를 반영한 기준과 이번 실사 차이로 소모를 구한다. 판매의 레시피 예상량을 미리 차감하지 않는다.
- [ ] T-010-03: 소모는 해당 기간 그 재료를 직접 참조한 메뉴의 판매 개수 비율로 배분한다. A 3개·B 1개, 소모 400g이면 A 300g·B 100g이다. 레시피 사용량 비율로 나누지 않는다.
- [ ] T-010-04: 별도 명시 폐기는 판매 소모에서 제외한다. 판매가 없으면 미배분 소모로 보존하고 자동 폐기나 임의 메뉴 귀속을 만들지 않는다.
- [ ] T-010-05: 명시 폐기 뒤 잔량이 있으면 기존 총원가를 잔량에 배분한다. 전량 명시 폐기는 남은 원가를 손실로 종료하며 다음 입고에 이월하지 않는다.
- [ ] T-010-06: 소모로 감소한 수량은 적용 평균 단가의 원가를 함께 차감한다. 실사 차이를 폐기로 분류해 잔존 가치에 전부 남기던 기존 규칙과 구분한다.
- [ ] T-010-07: 원인 불명 초과는 누락 변동을 먼저 확인한 뒤 기존 단가로 조정한다. 적용 단가가 없으면 금액을 확인한다. 미확인 품목의 이전 실사 시점·수량은 유지한다.
- [ ] T-010-08: 첫 실사도 알려진 초기 수량/가치와 확정 입출고가 있으면 이를 기준으로 정산한다. 초기 기준을 알 수 없으면 실제 시작 수량/가치를 확인하며 이전 판매만으로 소모를 임의 역산하지 않는다. 이전 배분·폐기·생산 투입과 중복 처리하지 않는다.

## 검증 방법

이전 10kg·명시 폐기 1kg·현재 실사 6kg→판매 소모 3kg, 판매 비례 배분·판매 없는 기간·첫 실사·품목별 기간·0 잔량·초과·반복 확정 시나리오.

[T-007](T-007-receipts.md)의 조회 계약을 실사 화면에 연결하여 마지막 확인 수량·시각과 이후 확정 입출고를 구분하는지 확인한다. [T-008](T-008-production.md)의 생산 수량 충돌 때 보존한 입력과 실사 결과를 연결하고, T-002 계산 계약에 따른 실사 기준·생산 기록의 적용 순서에서 수량/원가 보존과 중복 반영 방지를 통합 검증한다. 기존 실사·생산 기록의 오입력 정정 연결은 T-012에서 검증한다.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

운영 정책 질문은 확정됐다. 화면 구성·스키마·오류 표시·정밀도 등은 T-002와 기존 구조에 맞춰 설계한다. 새 운영 판단이 필요하면 예시와 영향을 제시하고 해당 부분만 보류한다.

## 검증 결과

미실행 — 요구사항을 티켓으로 전환한 상태다. 수용 기준 체크는 실제 구현·검증 근거가 생긴 뒤 갱신한다.
