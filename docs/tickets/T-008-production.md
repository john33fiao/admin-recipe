# T-008: 실측 손질·비축 생산과 원가 이월

- 상태: 완료 — 실제 생산·정확 원가 이월·원자성·조회 검증
- 단계: 1차
- 작성일: 2026-10-24
- 관련 요구: C-01~C-03, D-04~D-05, P-04·P-08
- 선행: [T-004](T-004-recipes-and-costs.md), [T-007](T-007-receipts.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

실제 투입·확보 수량으로 원물과 결과물 재고를 연결하고 투입 원가를 보존한다.

## 포함 범위

원물/손질분/비축품의 투입과 결과물 생산, 실제 확보량·원가 배분·전환 이력 조회를 제공한다.

## 제외 범위

기준 수율 자동 산정·생산 계획 자동 배정.

## 수용 기준

- [x] T-008-01: 투입 여러 재료와 실제 결과물 수량을 기록하며 기준 수율로 재고를 생성하지 않는다. 손질분 재손질도 지원한다.
- [x] T-008-02: 원물 3kg·30,000원을 투입해 2kg 결과물이면 결과물 총원가 30,000원과 15원/g을 보존한다.
- [x] T-008-03: 여러 결과물의 배분 합은 투입 원가와 같으며 0원 결과물을 허용한다. 주 결과물 100%·나머지 0%를 기본으로 하고 수정할 수 있다.
- [x] T-008-04: 투입 차감과 결과물 추가는 한 확정 기록이다. 재시도·실패로 한쪽만 반영하지 않는다.
- [x] T-008-05: 비축 생산의 하위 재료 투입은 알려진 확정 변동으로 처리하고 상위 판매에 다시 배분하지 않는다.
- [x] T-008-06: 판매에 근거한 예상 재고 부족으로 생산 입력을 막지 않는다. 실제 투입·확보 수량이 기록 기준과 충돌하면 충돌 내용과 확인할 누락 입고/실사를 안내하고 입력을 보존하며 결과를 임의 축소하지 않는다. 이 티켓에서는 T-002 계산 계약에 따른 충돌 처리와 보정 결과·생산 기록의 연결을 가상 보정 결과로 검증한다. 실제 실사 연결은 [T-010](T-010-stocktake-and-waste.md), 기존 기록의 정정 연결은 [T-012](T-012-corrections-and-versions.md)에서 완성하며 두 후속 기능 구현을 이 티켓의 완료 조건으로 요구하지 않는다.

## 검증 방법

1→1·여러 투입→여러 결과·서로 다른 단위·0원 결과·재시도의 수량/원가 보존 단위/통합/UI 테스트. 기록상 투입 가능량과 실제 투입량이 다른 가상 사례에서 충돌 안내·입력 보존을 확인한다. 실사 기준·보정 결과·생산 기록의 적용 순서는 T-002 계산 계약을 따르며 수량/원가를 한 번만 반영하는지 검증한다. 실제 생산과 실사의 연결·수량/원가 보존은 T-010, 기존 기록 정정과 생산 기록의 연결은 T-012에서 통합 검증한다.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

운영 정책 질문은 확정됐다. 화면 구성·스키마·오류 표시·정밀도 등은 T-002와 기존 구조에 맞춰 설계한다. 새 운영 판단이 필요하면 예시와 영향을 제시하고 해당 부분만 보류한다.
