# T-023: 2차 실제 작업시간 기록과 시계열

- 상태: 2차 — 구체화/착수 대기
- 단계: 2차
- 작성일: 2026-10-24
- 관련 요구: D-06
- 선행: [T-021](T-021-first-release-verification.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

비정기적으로 측정한 조리 작업시간을 생산 조건과 함께 비교한다.

## 포함 범위

메뉴별 실제 작업일·시간·생산량·조건을 사후 입력하고 실제 날짜 간격의 시계열로 조회하는 범위를 구체화한다.

## 제외 범위

자동 타이머 필수화·자동 인건비·설비 일정.

## 수용 기준

- [ ] T-023-01: 1차 조리 공정의 설명/예정 시간과 실제 측정 이력을 구분한다.
- [ ] T-023-02: 비정기 사후 입력·같은 날 여러 측정·미측정 날짜를 구별한다. 입력일과 실제 작업일을 별도로 보존한다.
- [ ] T-023-03: 생산 수량·단위·시작 재료 상태·측정 공정·레시피 버전과 함께 기록한다.
- [ ] T-023-04: 기간별 총시간/단위 생산량당 시간 비교에서 생산 규모·범위가 다른 값을 같은 조건처럼 합치지 않는다.
- [ ] T-023-05: 측정 범위·필수 필드·표준시간 갱신 방식을 착수 때 확정하고 기능 수용 테스트를 작성한다. 실제 인건비 계산은 T-029에서 별도 결정한다.

## 검증 방법

가상 비정기 측정·0/미입력·서로 다른 생산 조건·레시피 변경 사례로 요구 검토 후 저장/그래프 테스트.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

2차 착수 시 측정 범위·표준시간 적용·필수 입력 확정

## 검증 결과

미실행 — 요구사항을 티켓으로 전환한 상태다. 수용 기준 체크는 실제 구현·검증 근거가 생긴 뒤 갱신한다.
