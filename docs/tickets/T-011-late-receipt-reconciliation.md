# T-011: 실사에 포함된 지연 입고 보정

- 상태: 완료 — 명시 포함 입고·경계 안내 검증. 실제 관측 정정도 T-012에서 연결
- 단계: 1차
- 작성일: 2026-10-24
- 관련 요구: D-02~D-04, O-01, P-07·P-08
- 선행: [T-007](T-007-receipts.md), [T-010](T-010-stocktake-and-waste.md)
- 기준: [요구사항](../REQUIREMENTS.md), [최신 운영 결정](../decisions/ADR-007-consumption-and-ticket-scope.md)

## 목적

늦게 입력한 입고를 실사·판매 소모에 중복 반영하지 않고 현재 재고 가치를 보정한다.

## 포함 범위

입고일·관련 실사·이미 포함된 수량 확인, 현재 수량/금액 보정 미리보기와 확정, 원기록 연결을 제공한다.

## 제외 범위

입고일 기준 전체 과거 원가 재계산·자동 판매 귀속 추정.

## 수용 기준

- [x] T-011-01: 사용자가 관련 실사와 이미 포함된 수량을 선택·확인한다. 자동 추정을 확정값으로 저장하지 않는다.
- [x] T-011-02: 실사 10kg에 이미 포함된 과거 입고 3kg을 등록해도 13kg으로 만들지 않는다. 미포함 수량만 새로 반영한다.
- [x] T-011-03: 실사 초과에서 이미 계상한 금액과 실제 구입금액의 차이를 보여주고 현재 보유 가치·별도 보정의 합이 맞도록 처리한다.
- [x] T-011-04: 실사 후 일부 판매·전환·명시 폐기가 있던 사례를 계약에 따라 처리한다. 지연 입고만으로 과거 판매·원가 기록을 소급 재작성하지 않는다.
- [x] T-011-05: 선택한 실사·입고·이전 배분/보정과 결과를 연결하여 동일 수량·금액을 두 번 정산하지 않는다.
- [x] T-011-06: 0원 가격·실사 후 소모·참조 실사 정정 같은 경계는 적용 결과 또는 해결 절차를 명시하고 조용히 무시하지 않는다.

## 검증 방법

전부/일부 실사 포함·실사 후 사용·재시도·정정된 실사·기존 단가와 실제 가격 차이의 가상 연속 원장 통합 테스트.

구현 티켓은 [공통 완료 조건](README.md#공통-완료-조건)의 실제 명령에서 영향 범위를 선택한다. 후속 구체화 티켓은 먼저 미결정을 확정하고 구현·검증 작업을 나눈다.

## 남은 결정과 구현 메모

운영 정책 질문은 확정됐다. 화면 구성·스키마·오류 표시·정밀도 등은 T-002와 기존 구조에 맞춰 설계한다. 새 운영 판단이 필요하면 예시와 영향을 제시하고 해당 부분만 보류한다.

## 검증 결과

[구현 계획](T-011-plan.md)과 [검증 기록](T-011-verification.md)에 기준별 근거와 RTD After13을 기록했다. Rust381개 각각·UI66·브라우저73개 각각·키보드·화면13장과 최종 build/정적 검사를 확인했다. 기존 schema10 원응답·JSON23건을 보존하며 수량/금액·예약·복구 경계를 검증했다. 실제 관측 정정·포함 연결 개정과 중복 가치 방지는 [T-012 검증](T-012-verification.md)에서 정상 저장/API·브라우저 경로로 연결했다. 실제 반품은 T-013에서 검증한다. 지정 실제 자료 시연과 별도 장비·실제 절전 검증은 이 완료 판정에 포함하지 않는다.
