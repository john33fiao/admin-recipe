# 참고 자료

공개 가능한 요구사항 참고 자료와 실행 검증 근거·외부 문서의 출처를 관리한다.

- [T-019 호환·같은 OS 이동 검증](T-019-compatibility-verification.md): 합성/정상 API 캡처 출처, 전체 폴더 이동·복원과 DB-only 한계.
- [T-031~T-033 일괄 입력 검증](T-031-T-033-verification.md): CSV/직접 표/편집 통합, 수용 기준·실제 UI/API·재시도/복원·RTD.
- [T-021 통합·시연·규모 측정](T-021-integration-verification.md): 최종 가상 연결·지정 격리 시연·실제 비용과 외부 미검증.
- [T-021 보안 검토](T-021-security-review.md): 의존성 권고·세션/파일/복원/입력·공개 산출물 경계.
- [T-021 Windows 재개 검증](T-021-windows-resume-verification.md): 새 x64 빌드·업무/일괄 입력·복원 영향, 종료 검증 생략과 필수 외부 미검증.

- 원본을 이동하기 전에 소유자와 보존할 출처를 확인한다.
- 외부 자료는 출처와 이용 조건을 확인하고 필요한 범위만 보관한다.
- 운영 자료, 비공개 시트·디자인 링크, 개인 경로와 계정 정보는 공개 파일에 넣지 않는다.
- 로컬 검토 자료는 Git에서 제외한 `private/`에 둔다. 새 복제본에는 이 폴더가 제공되지 않는다.
- 확정된 제품 요구사항과 수용 기준은 공개 개발 문서에서 독립적으로 이해할 수 있게 정리한다.
