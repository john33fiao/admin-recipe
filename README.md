# 레시피 관리자 어드민

- 식당 "순창한상" 오픈 준비를 위해 사용합니다

셰프 1명이 레시피와 식당 운영 정보를 관리하는 웹 UI 기반 설치형 앱을 직접 개발합니다. 초기에는 로컬에서 사용하고 안정화 후 별도 서버로 이관합니다. 소스코드를 공개할 계획이며, 운영 데이터는 공개 코드와 분리합니다.

## 현재 상태

요구사항과 개발 문서를 정리 중이며 실행 가능한 앱, 패키지 설정, 빌드·테스트 명령은 아직 없습니다.

- **1차:** 레시피·식재료 원가·발주·입고·판매·재고
- **2차:** 내일 메뉴 계획·작업시간
- **백로그:** 시설 점검
- **초기 운영:** 단일 바이너리 배포, 로컬 SQLite 저장, JSON 백업. DB 파일과 JSON 백업 파일은 모두 실행 바이너리와 같은 폴더에 보관

대상 OS·구현 기술·기기 간 접속·백업 세부 정책은 미정입니다. PC·태블릿·모바일 크기에 대응하는 화면과 라이트·다크 요구는 유지합니다. 기존 화면 초안은 레이아웃 참고안이며 최종 GUI가 아닙니다. [결정 기록](docs/decisions/ADR-002-first-release-and-local-storage.md)에서 확정 범위와 남은 판단을 확인할 수 있습니다.
