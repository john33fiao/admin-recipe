# 레시피 관리자 어드민

- 식당 "순창한상" 오픈 준비를 위해 사용합니다

셰프 1명이 PC·태블릿·모바일 웹에서 레시피와 식당 운영 정보를 관리하는 웹 어드민을 직접 개발합니다. 소스코드를 공개할 계획이며, 운영 데이터는 공개 코드와 분리합니다.

## 현재 상태

요구사항과 개발 문서의 초기 정리 단계입니다. 실행 가능한 애플리케이션, 패키지 설정, 빌드·테스트 명령은 아직 없습니다. 첫 버전 범위, 기술 스택, 저장·호스팅 방식은 결정 전입니다.
