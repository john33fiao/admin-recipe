# 레시피 관리자 어드민

- 식당 "순창한상" 오픈 준비를 위해 사용합니다

셰프 1명이 레시피와 식당 운영 정보를 관리하는 웹 UI 기반 설치형 앱을 직접 개발합니다. 초기에는 로컬에서 사용하고 안정화 후 별도 서버로 이관합니다. 소스코드를 공개할 계획이며, 운영 데이터는 공개 코드와 분리합니다.

## 현재 상태

요구사항과 개발 문서를 정리 중이며 실행 가능한 앱, 패키지 설정, 빌드·테스트 명령은 아직 없습니다.

- **1차:** 레시피·식재료 원가·발주·입고·판매·재고
- **2차:** 내일 메뉴 계획·작업시간
- **백로그:** 시설 점검·부분 입고·보관 위치
- **초기 운영:** 단일 PC 사용. 바이너리 하나와 옆의 `db/` 폴더 하나로 실행하며 SQLite·JSON 변경 기록·사진을 이 폴더에 보관

마감에 메뉴 판매·폐기를 입력하고 확인한 품목의 현재고를 대조합니다. 부족분은 자동 폐기로 기록하며 손실 원가는 남은 재고에 배분합니다. 현재 보유량·평균 원가·단위당 가격을 조회합니다.

데이터 변경마다 JSON으로 기록하고 무기한 보관하며, 복원은 선택한 상태로 전체를 되돌립니다. 비밀번호 잠금은 없습니다. 다른 PC·Mac에서는 OS에 맞는 빌드로 같은 데이터를 사용하며 사진까지 옮길 때는 `db/` 전체를 함께 가져갑니다.

운영 예외 네 가지와 Rust 백엔드·Nuxt 프론트엔드를 확정했습니다. 바이너리가 로컬 서버와 웹브라우저를 열며 WebSocket heartbeat 연결이 일정 시간 끊기면 종료합니다. 앱 내부 업데이트는 제외하고 새 앱이 이전 DB를 계속 지원합니다. Electron은 현재 고려하지 않습니다. [기술 결정 기록](docs/decisions/ADR-005-rust-nuxt-local-server.md)과 [첫 구현 준비 티켓](docs/tickets/T-001-portable-local-app.md)에 세부 제안·미검증 항목을 정리했습니다. 기존 화면 초안은 레이아웃 참고안입니다.
